# Архитектурные решения — video-kb

### Правка ASR — правилами TSV, а не моделью — дата неизвестна

- **Контекст.** Русские автосабы на техническом материале ломают английские термины
  (ONNX → «он X», throughput → «срупут»).
- **Выбор.** `normalize.py` применяет регулярки из TSV по порядку и считает
  срабатывания; `.raw.md` не меняется; неоднозначное помечается `⟦?⟧`.
- **Альтернативы.** Переписывание текста моделью — отвергнуто: замену нельзя
  пересчитать, оспорить и откатить (докстринг `normalize.py`).
- **Граница проверенного.** Шероховатости по лекциям — в `SKILL.md`.

### Адрес цитаты проверяется программно — дата неизвестна

- **Контекст.** На одной из первых лекций `verify_kb.py` нашёл четыре цитаты,
  приклеенные не к тому месту, после вычитки глазами (`SKILL.md`, режим verify).
- **Выбор.** `verify_kb.py` сверяет таймкоды с блоками транскрипта, `check_quotes.py`
  — дословность и блок ±1, `locate.py` считает адрес.
- **Альтернативы.** Ручная сверка — так делалось до `check_quotes.py`.

### Отдельный репозиторий и исполняемые спеки — 2026-11-17

- **Контекст.** Скилл жил только папкой `~/.claude/skills/video-kb/` без истории и
  тестов.
- **Выбор.** Отдельный репозиторий `video-kb`, установка симлинком; поведение
  скриптов как есть описано спеками OpenSpec с тестом на каждый сценарий. Похожее на
  дефекты не чинилось, а зафиксировано требованиями (SUB-3, NRM-6, LOC-6, QUO-4,
  QUO-6).
- **Альтернативы.** `SPEC.md` с пунктами — выбран OpenSpec: требование = ID = тест.
- **Граница проверенного.** Спеки описывают поведение скриптов, но не промпт
  `SKILL.md`; качество базы, которую собирает агент, тестами не мерится.
