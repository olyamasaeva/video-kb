# video-kb — что за проект

## Зачем

Скилл Claude Code: видеокурс на YouTube → база знаний с проверяемыми адресами.
Автосубтитры чинятся TSV-правилами со счётчиком замен (сырой транскрипт не трогается),
выход — конспекты с кликабельными таймкодами, карточки практик с «Границами» и
словарь терминов. Инвариант: у каждого утверждения в базе есть адрес — минута видео,
слайд или файл кода (`SKILL.md`, «Инварианты»).

Чем измеряется: зелёные `verify_kb.py` и `check_quotes.py` по базе. Отдельного eval
у скилла нет.

## Модули

| Модуль | Что делает | Точка входа |
|---|---|---|
| `SKILL.md` | промпт: режимы add / verify / init / finalize / skills, форматы, шероховатости | агент |
| `scripts/json3_to_text.py` | json3 → транскрипт блоками с таймкодами | `python3 scripts/json3_to_text.py F.json3` |
| `scripts/normalize.py` | TSV-правила → нормализованный транскрипт и отчёт | `python3 scripts/normalize.py IN --rules … --out OUT` |
| `scripts/locate.py` | адрес дословной цитаты | `python3 scripts/locate.py T.md "цитата"` |
| `scripts/check_quotes.py` | дословность и адрес всех «цитат» базы | `python3 scripts/check_quotes.py KB_ROOT` |
| `scripts/verify_kb.py` | ссылки, таймкоды, формат карточек | `python3 scripts/verify_kb.py KB_ROOT` |
| `openspec/specs/` | контракт поведения скриптов | `uv run pytest` |

## Данные

Своих нет. Базы знаний, собранные скиллом, живут вне репозитория (паспорт базы —
раздел «База курса» в `SKILL.md`); тесты строят входы в `tmp_path`.

## Потребитель результата

Пользователь скилла и агенты, собирающие базы знаний по видеокурсам.
