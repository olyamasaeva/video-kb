# Proposal

## Why

`video-kb` готовится к публикации. Внешнее ревью безопасности (2026-11-17) нашло десять
проблем: личный контекст автора в отслеживаемых файлах, утечку путей правил и имён скиллов в
отчёт `skill_evidence.py`, показ всех реплик сессии без фильтра, чтение и запись через
символические ссылки, падение на враждебных журналах и квадратичный разбор слов, регулярки
пользователя без предела времени в `normalize.py`, открытые права и лишние записи в кеше,
общий кеш у баз с одинаковым именем и `yt-dlp`, пишущий в текущую папку. Решения автора:
история git остаётся приватной, публикуется отдельный чистый снимок; содержимое HEAD
обезличивается сейчас; хук `repo-shape` остаётся в репозитории и исключается при сборке
снимка.

## What Changes

- `skill_evidence.py`: в отчёте вместо имён скиллов и путей правил — непрозрачные id, связка
  только в приватном кеше; по умолчанию без папок текущего каталога (SKL-5, SKL-6, SKL-10).
- `--показать` печатает только совпавшие реплики в окне, фрагментом не длиннее 400 знаков,
  с вымаранными секретами и пометкой, что текст журнала — данные, а не инструкции (SKL-9).
- Символические ссылки: журналы вне корня и ссылки не читаются, запись через ссылки
  отклоняется (SKL-11).
- Враждебные журналы: записи неверной формы пропускаются, ошибки чтения и сверхдлинные строки
  дают неполный скан с кодом 4; сопоставление без всех префиксов слов (SKL-12, SKL-13).
- Кеш: папка 0700, файл 0600, только совпавшие сессии; пространство имён — хеш пути базы,
  id сессии 16 hex-знаков (SKL-14, SKL-15).
- `normalize.py`: правила применяются в отдельном процессе с пределом времени на правило и
  строку, предел размера входа; превышение — код 3 без записи (NRM-7, NRM-8).
- `SKILL.md`: `yt-dlp` пишет в `<база>/sources/subs`; согласие пользователя перед сканом
  журналов и перед показом реплик (PRM-1, PRM-2).
- Обезличивание текущих файлов и архива изменений; тест-сторож приватности (PUB-1).

## Capabilities

### New Capabilities
- `prompt`: проверяемые инварианты промпта `SKILL.md`. ID с префиксом PRM.
- `publication`: что допустимо в отслеживаемых файлах публикуемого репозитория. ID с
  префиксом PUB.

### Modified Capabilities
- `skills`: SKL-5, SKL-6, SKL-9 меняются; новые SKL-10…SKL-15.
- `normalize`: новые NRM-7, NRM-8.

## Impact

`scripts/skill_evidence.py`, `scripts/normalize.py`, `SKILL.md`, `README.md`, `AGENTS.md`,
`openspec/config.yaml`, `.context/`, `CHANGELOG.md`, `hooks/no_comments.py`,
`scripts/json3_to_text.py`, архив `openspec/changes/archive/`, тесты. История git не
переписывается.
