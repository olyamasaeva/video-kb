## Purpose
Что допустимо в отслеживаемых файлах публикуемого репозитория: без личного контекста автора. Где: все файлы `git ls-files`, тест `tests/test_no_personal_context.py`.

## ADDED Requirements

### Requirement: PUB-1 В отслеживаемых файлах нет личного контекста
Ни один файл из `git ls-files`, кроме самого теста-сторожа, MUST NOT содержать строк из списка теста: личные пути, имена автора, его баз и чекаутов, id его чатов.

#### Scenario: PUB-1 сторож приватности
- **WHEN** тест читает все отслеживаемые файлы, кроме себя
- **THEN** ни в одном нет строк из списка
- Тест: `tests/test_no_personal_context.py::test_pub1_no_personal_context`
