# Spec Delta

## Purpose
Проверка, нужны ли из базы знаний скиллы для агента: доказательства из журналов сессий пользователя, покрытие уже установленными скиллами и правилами, проверка собранного скилла. Где: `scripts/skill_evidence.py`, `scripts/skill_lint.py`.

## ADDED Requirements

### Requirement: SKL-1 Кандидаты и фразы читаются из TSV базы
`skill_evidence.py <база>` SHALL читать `<база>/skills/кандидаты.tsv` (кандидат, карточки, когда) и `<база>/skills/запросы.tsv` (кандидат, фраза); фраза для неизвестного кандидата или нет файла MUST давать код 2 и сообщение в stderr с именем файла и строкой.

#### Scenario: SKL-1 фраза неизвестного кандидата
- **WHEN** в `запросы.tsv` есть строка с кандидатом, которого нет в `кандидаты.tsv`
- **THEN** код 2, в stderr имя файла и номер строки
- Тест: `tests/test_skill_evidence.py::test_skl1_unknown_candidate`

### Requirement: SKL-2 Учитываются только реплики пользователя
Скрипт SHALL искать фразы только в репликах пользователя: Claude Code — записи `type: user` без `isMeta`, `isSidechain`, `isCompactSummary`, текстовые части без `tool_result`; Codex — `event_msg` типа `user_message` вне сессий субагентов (`source.subagent`). Ответы агента, вывод инструментов и вставки харнесса (`<…`, `[Request interrupted`, `[bb `, `You are continuing an earlier`) MUST NOT давать совпадений.

#### Scenario: SKL-2 фраза в ответе агента не считается
- **WHEN** фраза кандидата встречается в синтетическом журнале только в ответе ассистента и в `tool_result`
- **THEN** у кандидата 0 сессий
- Тест: `tests/test_skill_evidence.py::test_skl2_only_user_turns`

#### Scenario: SKL-2 сводка компактизации и сессия субагента Codex не считаются
- **WHEN** фраза есть только в записи Claude Code с `isCompactSummary`, в служебных вставках `[bb system] …` и `<command-message>…` и в `user_message` сессии Codex с `source.subagent` в `session_meta`
- **THEN** у кандидата 0 сессий
- Тест: `tests/test_skill_evidence.py::test_skl2_compact_summary_and_codex_subagent`

#### Scenario: SKL-2 оба формата журналов
- **WHEN** фраза есть в реплике пользователя одного журнала Claude Code и одного журнала Codex
- **THEN** у кандидата 2 сессии, у каждой указан движок
- Тест: `tests/test_skill_evidence.py::test_skl2_both_engines`

### Requirement: SKL-3 Совпадение без регистра и по основе слова, в пределах окна
Фраза SHALL совпадать без учёта регистра и `ё`/`е`, если каждое её слово встречается в одной реплике как префикс слова реплики длиной не меньше основы слова фразы (основа — слово без последних двух букв, но не короче 4 букв). Учитываются только реплики не старше `--дней` (по умолчанию 60). Сессия считается один раз на кандидата.

#### Scenario: SKL-3 другая форма слова
- **WHEN** фраза «напишу eval агенту», реплика «Напиши евал… нет, eval для агентов»
- **THEN** совпадение засчитано
- Тест: `tests/test_skill_evidence.py::test_skl3_word_forms`

#### Scenario: SKL-3 реплика старше окна
- **WHEN** единственная реплика с фразой старше `--дней 30`
- **THEN** у кандидата 0 сессий
- Тест: `tests/test_skill_evidence.py::test_skl3_window`

### Requirement: SKL-4 Сессии сборки базы исключаются
Сессия, у которой рабочая папка внутри базы или в репликах есть вызов `video-kb`, SHALL исключаться из подсчёта, а число исключённых — печататься в отчёте; флаг `--включить-сборку` MUST отключать исключение.

#### Scenario: SKL-4 сессия в папке базы
- **WHEN** единственная сессия с фразой имеет cwd внутри базы
- **THEN** у кандидата 0 сессий, в отчёте «исключено сессий сборки: 1»; с `--включить-сборку` — 1 сессия
- Тест: `tests/test_skill_evidence.py::test_skl4_build_sessions_excluded`

### Requirement: SKL-5 В отчёте нет текста реплик и путей
`<база>/skills/доказательства.json` и `.md` SHALL содержать по сессии только id (8 hex-знаков хеша пути журнала), движок, дату и совпавшие фразы; текст реплик, пути проектов и заголовки сессий MUST NOT попадать в отчёт. Связка id → путь журнала SHALL писаться в `~/.cache/video-kb/<имя базы>/sessions.json` (корень переопределяется `--кеш`).

#### Scenario: SKL-5 отчёт без текста и путей
- **WHEN** реплика с фразой содержит уникальную строку-маркер, а журнал лежит в папке с маркером в имени
- **THEN** ни одного маркера нет в файлах `skills/`, путь журнала есть в `sessions.json` под кешем
- Тест: `tests/test_skill_evidence.py::test_skl5_no_text_no_paths`

### Requirement: SKL-6 Покрытие скиллами и правилами, бюджет описаний
Скрипт SHALL собирать установленные скиллы (`SKILL.md` в папках из `--скиллы`, по умолчанию `~/.claude/skills`, `~/.codex/skills`, `~/.agents/skills`, `.claude/skills` текущей папки) и правила (`CLAUDE.md`, `AGENTS.md`, `.claude/rules/*.md` из `--правила`); для кандидата SHALL выводить скиллы, в `description` которых, и файлы правил, в абзаце которых встречается хотя бы одна его фраза по правилу SKL-3; SHALL печатать бюджет: число скиллов и суммарную длину полей `description`.

#### Scenario: SKL-6 кандидат покрыт скиллом
- **WHEN** описание установленного синтетического скилла содержит фразу кандидата
- **THEN** у кандидата в покрытии имя этого скилла, в бюджете 1 скилл и длина его описания
- Тест: `tests/test_skill_evidence.py::test_skl6_coverage_and_budget`

#### Scenario: SKL-6 кандидат покрыт правилом
- **WHEN** фраза кандидата есть в синтетическом `AGENTS.md`
- **THEN** в покрытии кандидата этот файл правил
- Тест: `tests/test_skill_evidence.py::test_skl6_rules`

### Requirement: SKL-7 Отчёт говорит, сколько журналов нашлось
Отчёт SHALL печатать по движку число журналов в окне и дату самого старого; если журналов нет ни у одного движка, отчёт MUST содержать строку «журналов нет» и код возврата SHALL быть 3.

#### Scenario: SKL-7 журналов нет
- **WHEN** папки журналов пусты
- **THEN** код 3, в отчёте «журналов нет»
- Тест: `tests/test_skill_evidence.py::test_skl7_no_logs`

### Requirement: SKL-8 Проверка собранного скилла
`skill_lint.py <папка скилла>` SHALL возвращать 0, если у `SKILL.md` есть frontmatter с `name` (совпадает с именем папки, строчные латинские буквы, цифры и дефис) и непустым `description` не длиннее 1024 знаков, а все ссылки на `.md`-файлы с абсолютными путями существуют; иначе код 1 и по строке на нарушение.

#### Scenario: SKL-8 ссылка на несуществующую карточку
- **WHEN** в теле `SKILL.md` ссылка на отсутствующий файл карточки
- **THEN** код 1, строка с этим путём
- Тест: `tests/test_skill_lint.py::test_skl8_missing_card`

#### Scenario: SKL-8 корректный скилл
- **WHEN** frontmatter правильный, ссылки существуют
- **THEN** код 0, вывод пуст
- Тест: `tests/test_skill_lint.py::test_skl8_ok`

### Requirement: SKL-9 Реплики одной сессии — только в терминал
`skill_evidence.py <база> --показать <id>` SHALL печатать в stdout реплики пользователя сессии с этим id (по связке из кеша) с датами и MUST NOT писать что-либо в `<база>/skills/`; неизвестный id MUST давать код 2.

#### Scenario: SKL-9 показ сессии
- **WHEN** после построения отчёта вызывается `--показать` с id найденной сессии
- **THEN** реплики сессии в stdout, файлы `skills/` не изменились
- Тест: `tests/test_skill_evidence.py::test_skl9_show_session`

#### Scenario: SKL-9 неизвестный id
- **WHEN** `--показать deadbeef` при пустом кеше
- **THEN** код 2
- Тест: `tests/test_skill_evidence.py::test_skl9_unknown_id`
