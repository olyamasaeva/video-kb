# Proposal

## Why

База знаний из курса — это карточки практик, но агенту нужны скиллы только там, где пользователь
действительно повторяет действие из курса. Автор публикует `video-kb` и требует, чтобы режим
**проверял нужность**: вердикт «скилл не нужен, хватит карточек» — штатный. Скиллов уже много,
их описания вытесняют друг друга (~1% окна на описания, t.me/llm_under_hood/960, /988).

## What Changes

- Новый режим `/video-kb skills <база>` в `SKILL.md`: кандидаты → поисковые фразы → доказательства
  из журналов сессий → покрытие установленными скиллами и правилами → вердикт агента → сборка
  одобренных скиллов или одного скилла-указателя на базу.
- Новый скрипт `scripts/skill_evidence.py` (stdlib): читает реплики пользователя из журналов
  Claude Code и Codex, считает совпадения фраз по кандидатам, исключает сессии сборки базы,
  собирает установленные скиллы и правила, пишет отчёт без текста реплик.
- Новый скрипт `scripts/skill_lint.py` (stdlib): проверяет собранный `SKILL.md` — frontmatter,
  длина описания, существование ссылок на карточки.
- Шаблон `templates/skill.md`.

## Capabilities

### New Capabilities
- `skills`: проверка нужности скиллов из базы и проверка собранного скилла. ID с префиксом SKL.

<!-- нет -->

## Impact

- `SKILL.md` (новый раздел режима), `scripts/skill_evidence.py`, `scripts/skill_lint.py`,
  `templates/skill.md`, тесты на синтетических журналах.
- Чтение (только чтение) `~/.claude/projects`, `~/.codex/sessions`, папок скиллов и правил
  пользователя; запись — `skills/` в базе и `~/.cache/video-kb/`.
