# Changelog — video-kb

Изменения скриптов и промпта, после которых прежние транскрипты, отчёты нормализации
или результаты verify не воспроизводятся. Хозяйство репозитория — по строке на шаг.

## [Unreleased]

- README и README.ru.md переделаны витриной: баннер, бейджи, кнопки, скриншоты базы CS329Z в светлой и тёмной теме (`docs/img/`); CI `.github/workflows/tests.yml` (`uv run pytest -q` на ubuntu).
- PUB-1: бинарные файлы (с нулевым байтом) сторож приватности пропускает — PNG давал ложный e-mail.
- Оформление как у соседних скиллов: английский `README.md`, русский — `README.ru.md`, `LICENSE` (MIT), `docs/img/social-preview.png`.
- Второй раунд ревью (изменение OpenSpec `harden-round-2`): личный список строк — вне
  репозитория, хук `private-denylist` (`hooks/denylist.py`), публичный тест — только общие
  маркеры; `skill_evidence.py` — вымарывание ключей и значений в кавычках, запись по
  дескрипторам папок без ссылок в предках, журнал проверяется после открытия, совпадение id
  покрытия и чужой `sessions.json` — код 2; `normalize.py` — ссылки в пути вывода — код 2,
  запись атомарная; `SKILL.md` — весь материал курса недоверенный.
- Третья проверка `harden-round-2`: ссылки в пути записи разрешены только до домашней
  папки (исключение «ссылка root» снято, системные пути вне дома — без ссылок, macOS
  `/tmp` — давать как `/private/tmp`); `skill_evidence.py` пишет отчёт и кеш атомарно,
  жёсткая ссылка не меняется; вымарывание учитывает `\"` и многострочные значения в
  кавычках; шаблоны скиллов — материал курса данные, а не инструкции.
- Подготовка к публикации (изменение OpenSpec `harden-for-publication`):
  `skill_evidence.py` — в отчёте только непрозрачные id сессий, скиллов и правил, связка
  в приватном кеше (0700/0600, только совпавшие сессии, пространство имён по пути базы,
  id сессии 16 hex вместо 8 — старые id и кеш недействительны); `--показать` печатает
  только совпавшие реплики окна фрагментом с вымаранными секретами; ссылки и файлы вне
  корня журналов не читаются, запись через ссылки — код 2; враждебные журналы — код 4
  «скан неполный»; по умолчанию без папок текущего каталога. `normalize.py` — правила в
  рабочем процессе с пределом `--timeout-sec`, вход до 20 МиБ, превышение — код 3.
  `SKILL.md`: `yt-dlp -P "$KB_ROOT/sources/subs"`, согласие перед журналами, личный
  контекст убран; тест-сторож `tests/test_no_personal_context.py`.
- Язык базы (изменение `add-output-language`, VER-5, VER-7): `<база>/video-kb.json`,
  схемы карточек `ru`/`en` в `verify_kb.py`.

- Режим `skills` (изменение OpenSpec `add-skills-mode`, SKL-1..9): `scripts/skill_evidence.py`
  — доказательства нужности скиллов из журналов Claude Code и Codex без текста реплик,

  собранного скилла; шаблоны `templates/skill.md`, `templates/kb-pointer.md`; раздел

  реплики пользователя.
