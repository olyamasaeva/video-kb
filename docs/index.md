# video-kb

Скилл Claude Code: видеокурс на YouTube → база знаний с проверяемыми адресами.
Автосубтитры чинятся детерминированно — TSV-правилами со счётчиком замен; выход —
конспекты с кликабельными таймкодами, карточки практик с «Границами», словарь
терминов. Ссылки, таймкоды и цитаты проверяются скриптами.

## Как устроено

| Шаг | Скрипт | Вход → выход |
|---|---|---|
| транскрипт | `json3_to_text.py` | `<NN>-<id>.ru.json3` → `transcripts/<L>.raw.md` |
| нормализация | `normalize.py` | `.raw.md` + `normalization/*.tsv` → `transcripts/<L>.md` + отчёт |
| адрес цитаты | `locate.py` | транскрипт + «цитата» → `[H:MM:SS](…?t=N)` |
| проверка цитат | `check_quotes.py` | база → MISS / SHORT / ADDR |
| проверка базы | `verify_kb.py` | база → ссылки, таймкоды, карточки |

Скрипты используют только стандартную библиотеку Python 3.10+ и вызываются по пути:
`python3 ~/.claude/skills/video-kb/scripts/verify_kb.py "$KB_ROOT"`.

## Режимы скилла

- `add <лекция>` — транскрипт, слайды, правила, конспект, карточки, словарь, verify.
- `verify` — `verify_kb.py` и `check_quotes.py`; красный verify — работа не закончена.
- `init <путь>` — новая база: субтитры, раскладка, копия скриптов.
- `finalize` — все лекции заново через итоговый `common.tsv`.

Полный промпт — `SKILL.md` в корне репозитория.
